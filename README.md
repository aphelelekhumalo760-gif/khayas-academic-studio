# KHAYA'S ACADEMIC STUDIO — SITE ONLY

This version intentionally contains **no study guides or preloaded resources**.

## What is included
- Sophisticated, high-contrast gentleman aesthetic.
- Study-pack advertising: R400 Paper 1, R700 Paper 1 + Paper 2, R150 individual topic, R300 three-topic bundle.
- House-call tutoring advertisement.
- WhatsApp enquiry buttons for 063 171 6485.
- Resource Cabinet with an **Add Resource** workflow.

## Adding guides later
Open `index.html` in a browser/Live Server and select **Manage Resources** or **Add a resource**. Add a PDF, grade, subject, title and description. Resources are stored locally in the browser using IndexedDB. They are not embedded in this clean package.

## VS Code
1. Extract this folder.
2. Open the folder in VS Code.
3. Install Live Server if needed.
4. Right-click `index.html` → **Open with Live Server**.

The resource cabinet is intentionally local-browser based. If you later want a public admin system where new PDFs appear for every visitor, connect it to a backend/storage service.
